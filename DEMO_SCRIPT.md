# Demo script (Congressional App Challenge · ~2 minutes)

Use the live site with **Demo Mode on** (default blue banner).

## Suggested narration

1. **Impact (15s)**  
   “This is The Algorithmic Loop—an app that teaches computer science through crochet. It helps students see math and AI, and helps makers generate real patterns.”

2. **Radial Topology (35s)**  
   Open the module → drag the 3D surface → raise the growth multiplier.  
   “When stitches grow too fast, the fabric ruffles. That’s hyperbolic geometry—made visible in 3D.”

3. **Modular Permutations (40s)**  
   Generate Pattern → enable Limit yarn / Stash Buster → Download PDF.  
   “This is graph coloring—no two neighbors share a color—plus stash limits so scarce yarn isn’t overused.”

4. **Texture Recognition (30s)**  
   Upload any fabric photo (mock results are instant in Demo Mode) → show attention map.  
   “This is explainable AI: not just a label, but where the network focused.”

5. **Close (10s)**  
   “Built in the browser with React, Three.js, and TensorFlow.js—STEM you can hold.”

## Tips

- Keep Demo Mode on for judging unless you specifically want live MobileNet.
- Have a PDF download and a sample image ready.
- If Wi‑Fi is weak, stay on Demo Mode and skip waiting for model download.
